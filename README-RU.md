# CypCut to OPC UA Gateway

Независимый .NET-шлюз для исследования телеметрии лазерных контроллеров и передачи нормализованных данных через OPC UA.

> **Статус: исследовательский проект / clean-room интеграция.** В репозитории находится независимый HTTP/JSON → OPC UA прототип. Отдельно в полевых условиях подтверждён канал CypCut/PCUI по TCP `20112`, однако независимый parser этого протокола пока не опубликован в репозитории.

[English version](README.md)

## Почему два порта

`HTTP/8080` — пример конфигурации открытого HTTP/JSON-прототипа, уже присутствующего в исходном коде.

`TCP/20112` — отдельный PCUI-канал, наблюдавшийся при работе с реальным станком. В рамках теста были получены бинарные кадры, извлечены `TagId`/`TagValue` и корректно проверен CRC. Это не означает, что TCP parser уже реализован в опубликованном коде.

## Полевой milestone

2 сентября 2026 года отдельная полевая reference-сборка поддерживала соединение с контроллером CypCut/PCUI по TCP `20112`.

- получены и структурно разобраны бинарные кадры;
- извлечены идентификатор и значение тега;
- CRC успешно проверялся;
- в одном наблюдении получено 14 892 кадров и 0 CRC-ошибок;
- получен диагностический блок `Protocol20112` и значение `NcState.SysState = 1`.

Семантика состояний (`Idle`, `Run`, `Pause`, `Alarm`, `Cutting`) ещё не считается подтверждённой.

Подробности: [docs/FIELD-VALIDATED-MILESTONE.md](docs/FIELD-VALIDATED-MILESTONE.md).

## Что есть в открытом прототипе

- HTTP/JSON collector с настраиваемым адресом и маршрутом;
- нормализация данных в OPC UA;
- конфигурационная проверка и self-test;
- несколько OPC UA endpoint'ов;
- режим консоли и Windows Service.

Все примеры используют сеть `192.0.2.0/24`, предназначенную только для документации.

## Граница публичной версии

В репозиторий не включены и не будут включаться:

- интеграция, адреса, идентификаторы или конфигурации сторонних платформ мониторинга;
- клиентские данные, реальные IP-адреса, серийные номера и логи производства;
- старые бинарные адаптеры, их документация и настройки;
- заимствованный или производный от закрытого ПО код.

Дальнейшая реализация TCP/20112 будет выполняться независимо, на основе собственных анонимизированных наблюдений и тестов.
